# Mangaku releases

Release builds of the **Mangaku** Android app, and the update feed the app reads.

- **Download:** the latest APK is under [Releases](https://github.com/Kamal142-D/mangaku-releases/releases/latest).
- **In-app updates:** Mangaku checks [`update.json`](update.json) each time it opens and offers new versions with their changes.

This repository holds release files only — no source code.
